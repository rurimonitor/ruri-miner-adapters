# RURI MINER MONITOR Adapter Catalog

Public, data-only adapter updates for the RURI MINER MONITOR Android app.

`catalog.json` schema: `{"schema":1,"adapters":[]}`. Initially empty: the app uses its embedded adapters. To fix/add a pool, put a full validated adapter object inside `adapters` and commit to `main`.

Do not commit wallet addresses, API keys, or private logs.
