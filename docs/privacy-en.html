RURI MINER MONITOR Privacy Policy

Effective date: October 20, 2026

RURI MINER MONITOR (the “App”) is a mining-pool monitoring application that uses public APIs or publicly accessible web lookup functions provided by mining pools to check the status of mining addresses or accounts registered by the user. The App does not require a separate developer-operated user account or backend server. Core user settings and monitoring data are stored on the device.

1. Information Processed by the App

  • Information entered directly by the user: public wallet addresses or miner/mining-account identifiers, selected coins and pools, aliases, and general settings.
  • Optional API credentials: read-only tokens required by certain official APIs such as F2Pool. These tokens are encrypted and stored on the device using Android Keystore and are excluded from normal backups.
  • Local monitoring records: hashrate, worker count, accepted/rejected shares, API status, and short error summaries. Status records are retained for up to 7 days and then automatically cleaned up.
  • Device Support ID: an app-specific identifier used to bind an offline reward coupon to one device. The raw Android ID is not displayed to the user or automatically transmitted to the developer.

The App does not ask users to enter wallet private keys, seed/recovery phrases, wallet passwords, or withdrawal credentials.

2. Network Connections

When checking a pool registered by the user, the App may connect directly to the mining pool's official or public HTTPS API or web page. During ordinary internet communication, the third-party service may process connection information such as IP address, request time, and request path. The privacy practices of each pool are governed by that operator's own policies.

The App may connect to a public GitHub repository to retrieve pool/API configuration and app-update information. Downloaded pool/API catalog data is signature-verified by the App and is configuration data only; the App does not download and execute remote executable code.

3. Advertising and Privacy Consent

The App may use Google AdMob. The Google Mobile Ads SDK may process information defined by Google, including IP address, device/app identifiers, advertising interactions, and diagnostic information, for ad delivery, fraud prevention, measurement, and diagnostics.

Where consent is required, the App uses Google User Messaging Platform (UMP) to request and manage advertising privacy choices. Where available or required, users can reopen advertising privacy choices from the App's Settings screen.

For more information about Google's data practices, see the Google Privacy Policy and AdMob privacy information.

4. Backups and Exports

User-initiated JSON backups may include registered pools, public wallet/miner addresses, and some general settings. Personal custom-adapter definitions, secret API tokens, advertising/reward entitlements, and monitoring status history are excluded from the normal settings backup. Monitoring history may be exported separately by the user as a CSV file.

Backup and CSV files are saved to a location chosen by the user and are not automatically uploaded to a developer server. Because backup files may contain public wallet addresses or other information entered by the user, users are responsible for storing those files securely.

5. Notification Permission

If the user enables lower-hashrate alerts, the App may request Android notification permission. Denying notification permission does not block other App functions, but lower-hashrate warning notifications may not be displayed.

6. Reports and Support

Pool/API reporting and customer-support features open the user's email app so that the user can review the message and send it manually. The App does not send email automatically. Users must not include passwords, private keys, seed phrases, withdrawal credentials, or unrestricted API secret keys in reports or support messages.

7. Retention and Deletion

  • Monitoring status records: up to 7 days.
  • Registered pools, wallet addresses, and general settings: until deleted by the user or until App data is reset/deleted.
  • Read-only API tokens: until deleted by the user or until App data is deleted; stored using Android Keystore.

Users can delete local App data by using the App's factory-reset function, Android's clear-app-data function, or by uninstalling the App.

8. Third-Party Services

Major third-party services that may be used by the App include Google AdMob/UMP, GitHub, and the public APIs or web services of mining pools selected by the user. Data processing by third-party services is subject to their own terms and privacy policies.

9. Changes to This Policy

This Privacy Policy may be updated when App functionality or the use of external services changes. When material changes are made, the updated policy will be made available through the App or the public distribution page.
