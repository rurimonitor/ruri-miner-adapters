# RURI MINER MONITOR 개인정보처리방침

시행일: 2026-10-20

RURI MINER MONITOR는 채굴 풀의 공개 API 또는 공개 웹 조회 기능을 이용하는 모니터링 앱입니다. 별도 개발자 운영 계정/서버를 요구하지 않으며 핵심 설정과 모니터링 데이터는 기기에 저장됩니다.

## 처리 정보
- 사용자가 입력한 공개 지갑 주소 또는 마이너/채굴 계정 식별자, 선택한 코인/풀, 별칭, 일반 설정
- F2Pool 등 일부 공식 API의 읽기 전용 토큰(Android Keystore 암호화 저장, 일반 백업 제외)
- 해시레이트, 워커 수, 승인/거부 셰어, API 상태 및 오류 요약(최대 7일)
- 오프라인 보상쿠폰 기기 귀속용 Support ID

앱은 개인키, 시드/복구문구, 지갑 비밀번호, 출금 권한 정보를 요구하지 않습니다.

## 네트워크 및 제3자 서비스
등록 풀의 공식/공개 HTTPS API 또는 웹페이지에 직접 연결할 수 있으며, 해당 서비스는 일반 통신 과정에서 IP 주소와 요청 메타데이터를 처리할 수 있습니다. GitHub 공개 저장소에서 서명된 풀/API 설정과 앱 업데이트 정보를 조회할 수 있습니다.

## 광고 및 동의
Google AdMob 및 Google UMP를 사용할 수 있습니다. Google Mobile Ads SDK는 광고 제공, 부정 사용 방지, 측정 및 진단을 위해 Google이 정한 정보를 처리할 수 있습니다. 동의가 필요한 지역에서는 UMP로 광고 개인정보 선택을 수집·관리합니다.

## 백업/내보내기
사용자 실행 JSON 백업에는 등록 풀, 공개 지갑/마이너 주소와 일부 일반 설정이 포함될 수 있습니다. 개인 커스텀 어댑터 정의, 비밀 API 토큰, 광고/리워드 권한 및 상태기록은 일반 백업에서 제외됩니다. 기록은 CSV로 별도 내보낼 수 있습니다.

## 알림
해시레이트 하한 알림을 위해 Android 알림 권한을 요청할 수 있습니다. 권한을 거부해도 다른 기능은 사용할 수 있으나 경고 알림은 표시되지 않을 수 있습니다.

## 제보/지원
제보 및 고객지원은 사용자의 이메일 앱을 열며 자동 전송하지 않습니다. 비밀번호, 개인키, 시드문구, 출금권한, 제한 없는 API 비밀키를 보내지 마세요.

## 보관/삭제
- 상태 기록: 최대 7일
- 등록 풀/지갑 주소/일반 설정: 사용자 삭제 또는 앱 데이터 삭제까지
- 읽기 전용 API 토큰: 사용자 삭제 또는 앱 데이터 삭제까지, Android Keystore 저장
